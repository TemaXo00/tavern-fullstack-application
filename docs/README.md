## Общие принципы

- Все HTTP-маршруты доступны через API Gateway с префиксом `/api`.
- Swagger-документация: `localhost:3000/api/docs`.
- gRPC-контракты описаны в `app/proto/*.proto`.
- Для ручной проверки gRPC-методов используется Bruno: workspace находится в `.bruno`.
- Межсервисное взаимодействие построено на RabbitMQ, audit-события собирает log-сервис.
